# English with Stick Man

Short animated stick-figure videos for learning everyday English. Each episode
is a dialogue between Sam and Mia with English voice-over and subtitles,
followed by a "listen and repeat" recap of the key phrases.

| # | Episode | Video |
|---|---------|-------|
| 1 | Nice to Meet You (greetings and introductions) | `videos/01-nice-to-meet-you.mp4` |
| 2 | At the Café (ordering food and drinks) | `videos/02-at-the-cafe.mp4` |
| 3 | Asking for Directions | `videos/03-asking-for-directions.mp4` |

## Make your own

The videos are generated by `make_videos.py`. To add an episode, append an
entry to `EPISODES` (scene, script lines, key phrases) and run:

```sh
pip install piper-tts pillow numpy   # ffmpeg is also required
python3 make_videos.py               # all episodes
python3 make_videos.py cafe          # only episodes whose name matches
```

The two English voices (about 60 MB each) are downloaded to `voices/` on the
first run.
