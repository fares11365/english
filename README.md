# english

**Vocab Builder** — a small English vocabulary app that runs in the browser. No install, no build step.

## Run it

Open `index.html` in any browser.

## Features

- **Flashcards** — tap a card (or press Space) to flip it. Choose *I know it* (→) or *Still learning* (←). Simple spaced repetition brings words back after longer gaps as you learn them.
- **Quiz** — multiple-choice questions, both word → meaning and meaning → word, with a running score.
- **My Words** — add your own words with part of speech, meaning and an example; search and delete words; reset progress.

Comes with 20 starter words (`words.js`). Your words and progress are saved in the browser's localStorage.

## Files

- `index.html` — page layout
- `style.css` — styles (light and dark mode)
- `app.js` — app logic
- `words.js` — starter word list
